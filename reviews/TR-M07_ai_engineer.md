# TR-M07 AI Engineer review

Passed: reusable prompt definitions are immutable ID/version assets with explicit
input/output contracts, owner, classification, constraints, and a static
template. Execution provenance binds the exact definition bytes, model/runtime,
context reference, redacted/protected fingerprints, and outcome evidence.

The validator rejects raw rendered prompts, raw input/output, hidden reasoning,
and recognisable credential literals. Restricted definitions require protected
reference capture.
